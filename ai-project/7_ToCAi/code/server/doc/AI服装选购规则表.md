# 公司商品种类与品牌总结

## 一、商品种类概览

根据现有商品数据，公司主营商品主要分为以下五大类：

### 1. 羽绒服/冬装外套
- **适用场景**：极寒环境、日常通勤、户外活动、工装作业
- **核心卖点**：高蓬松度鹅绒/鸭绒、防风防泼水、轻量保暖、抗静电、长款锁温
- **代表商品**：
  - 波司登极寒系列羽绒服
  - 北面1996复古羽绒服
  - 雪中飞短款修身羽绒服
  - 雅鹿工装风羽绒服
  - 艾莱依长款过膝羽绒服

### 2. T恤/夏季上衣
- **适用场景**：日常休闲、运动健身、防晒通勤、内搭
- **核心卖点**：吸湿快干、凉感抗菌、重磅耐洗、UPF防晒、柔软亲肤
- **代表商品**：
  - 优衣库AIRism棉混纺T恤
  - 耐克Dri-FIT运动T恤
  - 杰克琼斯纯棉重磅T恤
  - 蕉下冰丝防晒T恤
  - 李宁棉花糖系列T恤
  - GAP水洗做旧T恤

### 3. 工装风格服饰
- **适用场景**：户外作业、街头工装风、日常耐用穿搭
- **核心卖点**：耐磨帆布/斜纹棉、多口袋设计、抗撕裂、宽松版型、可调节
- **代表商品**：
  - 卡哈特工装夹克
  - 马登工装多口袋衬衫
  - Dickies双膝工装裤
  - Carhartt WIP背带工装裤
  - MO&Co. 工装风连体裤

### 4. 连衣裙/裙装
- **适用场景**：度假约会、职场通勤、晚宴派对、校园文艺
- **核心卖点**：法式复古、收腰显瘦、雪纺碎花、弹力棉、蕾丝拼接、丝绒鱼尾
- **代表商品**：
  - ZARA法式复古茶歇裙
  - ONLY方领泡泡袖连衣裙
  - 拉夏贝尔吊带碎花裙
  - 太平鸟娃娃领衬衫裙
  - 茵曼棉麻文艺连衣裙
  - 韩都衣舍蕾丝拼接小黑裙
  - 乐町彼得潘领针织连衣裙
  - 伊芙丽双排扣风衣连衣裙
  - Vero Moda丝绒吊带裙

### 5. 夹克/外套（春秋/薄款）
- **适用场景**：春秋换季、旅行便携、户外运动、机车风格
- **核心卖点**：经典牛仔版型、PU仿皮、抗皱便携、软壳防风抓绒、反光条速干
- **代表商品**：
  - Levi's牛仔夹克
  - ZARA皮夹克
  - 优衣库轻型便携夹克
  - 骆驼户外软壳夹克
  - 阿迪达斯运动夹克

## 三、总结

- **商品多样性**：覆盖**冬装（羽绒服）、夏装（T恤）、工装、裙装、春秋外套**五大品类，满足不同季节、场景和风格需求。
- **品牌梯队**：既有**国际运动/户外品牌**（北面、耐克、阿迪达斯、骆驼），也有**快时尚巨头**（优衣库、ZARA、GAP），还有**国内知名大众品牌**（波司登、李宁、太平鸟、伊芙丽等），以及**细分风格品牌**（工装类的卡哈特、Dickies；文艺风的茵曼；甜美风的乐町等）。
- **核心卖点覆盖**：保暖科技（鹅绒、拒水羽绒）、面料功能（速干、防晒、抗静电、防泼水）、版型设计（收腰、工装多袋、复古剪裁）、穿着场景（极寒、运动、通勤、宴会）均有对应商品。

> 注：此总结基于当前30款商品信息生成，可作为内部商品运营、选品分析或对外招商合作的基础参考文档。
