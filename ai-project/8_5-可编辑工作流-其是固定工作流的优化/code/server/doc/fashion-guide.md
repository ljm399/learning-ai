# 服装搭配攻略

## 一、身高体重与风格推荐

### 1.1 小个子女生（身高155cm以下）

**适合风格：**
- 甜美可爱风
- 简约干练风
- 轻熟优雅风

**穿搭要点：**
- 高腰设计能拉长腿部比例
- 选择短款上衣露出腰线
- 同色系穿搭显高挑
- 避免过于宽松的版型

**推荐单品：**
- 高腰A字裙
- 短款西装外套
- 高腰直筒裤
- 尖头高跟鞋

---

### 1.2 中等身高女生（身高155-168cm）

**适合风格：**
- 随意百搭风
- 轻熟御姐风
- 休闲运动风

**穿搭要点：**
- 可以尝试各种风格
- 注意上下身比例协调
- 适当露肤更显灵动

**推荐单品：**
- 中长款风衣
- 迷笛裙
- 牛仔外套
- 小白鞋

---

### 1.3 高个子女生（身高168cm以上）

**适合风格：**
- 酷飒街头风
- 高级简约风
- 欧美风

**穿搭要点：**
- 可以驾驭长款大衣
- 宽松版型更有范
- 注意强调腰线

**推荐单品：**
- 长款大衣
- 阔腿裤
- oversize卫衣
- 长靴

---

### 1.4 偏瘦体型（BMI < 18.5）

**适合风格：**
- 甜美荷叶边
- 复古风
- 叠穿混搭

**穿搭要点：**
- 选择有层次感的单品
- 荷叶边、蝴蝶结等装饰增加体量感
- 避免过于贴身的款式

**推荐单品：**
- 泡泡袖上衣
- A字蓬蓬裙
- 针织开衫
- 叠戴项链

---

### 1.5 标准体型（BMI 18.5-23.9）

**适合风格：**
- 几乎所有风格都可以尝试

**穿搭要点：**
- 根据场合选择合适的风格
- 突出自己的优点

**推荐单品：**
- 经典款风衣
- 修身连衣裙
- 简约T恤
- 牛仔短裤

---

### 1.6 偏胖体型（BMI > 23.9）

**适合风格：**
- 简约大气风
- 暗黑系
- 轻熟风

**穿搭要点：**
- 选择垂坠感好的面料
- 深色系更显瘦
- 强调腰线位置
- 避免过于紧身的款式

**推荐单品：**
- V领上衣
- 高腰阔腿裤
- 中长款开衫
- 直筒连衣裙

---

## 三、服装品类说明

| 品类代码 | 品类名称 | 说明 |
|---------|---------|------|
| `dress` | 连衣裙 | 各种款式的连衣裙 |
| `top` | 上装 | T恤、衬衫、针织衫等 |
| `bottom` | 下装 | 裤子、半裙等 |
| `coat` | 外套 | 西装、风衣、牛仔外套等 |
| `shoes` | 鞋履 | 高跟鞋、运动鞋、靴子等 |
| `accessory` | 配饰 | 项链、帽子、包包等 |
| `knitwear` | 针织品 | 毛衣、开衫等 |
| `jacket` | 短外套 | 短款外套、棒球服等 |
