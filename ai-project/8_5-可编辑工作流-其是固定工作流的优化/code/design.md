# 基本要求
1. 在前端准备一个工作流编辑页面。
2. 该页面允许用户用图形化的界面，拖拽编辑一个工作流
3. 工作流初始有一个开始和结束节点。
4. 然后用户可以往工作流里添加其他节点

# 节点类型
1. 请求节点-请求一个接口
2. AI智能体节点-请求调用大模型
3. 文码，拿到返回值传递下去。
5. 固定返回节点 - 该档节点-接受一个文档执行到该节点时提供这个文档
4. 自定义代码节点-执行提供的代节点固定返回一个文本内容
6. 判断节点 -该节点可以添加判断条件，让用户连线表达什么条件下可以连接到哪个节点

# 节点配置
每一个节点可以定义一些配置，从而让这个节点能更好的工作。 
1. 请求节点-需要接口地址，接口参数，token这些配置。接口参数可以从全局变量中选一个，也可以从节点工作结果中选一个。
2. AI智能体节点-可以配置system上下文，以及prompt，prompt可以从全局变量中选一个，也可以从节点工作结果中选一个
3. 文档节点-文档节点用户可以复制粘贴一个文档内容。到时候这个文档内容可以供之后的节点使用
4. 自定义代码节点-用户输入固定的nodejs代码
5. 固定返回节点 - 该节点运行用户提供固定的返回文本内容
6. 判断节点 - 该节点运行用户添加多个条件分支，每个分支用户可以自己输入判断条件逻辑

此外，所有的节点都有一个节点运行时提示词的选项，需要输入的部分都可以从全局变量和工作流节点结果选择变量

# 关于全局变量和工作流节点结果

节点工作结果 - 我们每定义一个节点，节点工作结果就可以多一个变量。供其他节点选择，
